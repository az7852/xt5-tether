# X‑T5 实机验收

状态：用户已确认 USB 收图可用，0.2.3 在真实手机与 X‑T5 固件 4.31 上完成 Wi‑Fi 两张 JPEG 接收和显示；下表其他矩阵项目仍待逐项验收。开发时按用户要求不使用安卓模拟器。

记录相机固件、手机型号、Android 版本、数据线型号和 USB 主机方向。App 的「连接指南 → 导出诊断日志」可以保存连接与传输信息。

| 场景 | 验收结果 |
| --- | --- |
| USB AUTO + JPEG FINE，连接并授权 | 显示 X‑T5 · USB，机身快门与拨盘仍可操作 |
| 单拍 10 张，每张间隔 2–3 秒 | 每张自动显示；完整文件数量与拍摄数量一致 |
| RAW+JPEG 单拍 5 张 | 两种原文件保留；RAF 内嵌预览可显示；JPEG 正确旋转 |
| 连续拍摄 / 快速单拍 | 核对实际文件数量、积压和耗时；不会因未释放临时缓冲区永久卡住 |
| 完整接收后再拍 | 相机复用句柄时仍接收新照片，不把新照片当作已接收 |
| 传输中拔线 | 显示断开，无不完整照片发布；已接收文件可回看/导出 |
| 重新插线 | 重新连接后继续接收，确认未接收的临时照片能恢复 |
| App 退后台、锁屏、恢复 | 前台通知存在，记录目标手机是否继续传输；回到界面可查看结果 |
| 点击断开 | 完成当前文件后停止；相机仍能正常操作 |
| USB CARD READER 模式 | 显示模式不匹配，不下载/删除卡中旧照片 |
| 相机菜单 / 回放 / 自动关机 | 给出错误；恢复拍摄状态后可手动重连 |
| 存储空间不足 | 停止接收，不释放没有完整保存的相机对象 |
| JPEG/RAF 导出 | 系统相册/下载可找到文件；大小与自动保存原文件一致 |
| 杀进程后重开 | 已完整保存的文件仍在「全部照片」；没有 `.part` 显示 |

测量“拍完马上显示”应对着相机和手机录屏/录像，分别记录快门到首个预览、到完整 JPEG 的时间。App 中的传输秒数只统计原文件下载，不代替这两个端到端指标。

先确认联机期间的 SD 卡记录行为，再用于正式拍摄。AUTO 与 FIXED 的差别以富士官方手册及机身固件为准。

## Wi‑Fi 验收

| 场景 | 验收结果 |
| --- | --- |
| 相机、手机连接同一路由器，机身无线联机固定 | 自动发现，完成握手，显示 `X‑T5 · Wi‑Fi` |
| 指定相机 IP | 可直接连接，或通过定向 PCSS 发现完成连接 |
| 非 /24 子网 | 使用实际前缀广播地址发现 |
| JPEG 连拍与 RAW+JPEG | 逐张落盘并自动显示，大小匹配，无未保存就释放的对象 |
| 传输中暂时关闭相机 Wi‑Fi | 中断后最多重连 3 次；已保存照片可回看 |
| 搜索中点断开 | 立即关闭发现套接字，不继续挂起搜索 |
| 路由器开启 AP 隔离或相机 IP 错误 | 说明连接失败，允许断开和再次尝试 |
| 改回 USB AUTO 并连接线缆 | USB 仍可正常收图 |

## 0.3.0 看图与平板检查

1. 手机竖屏：照片铺满可用宽度，连接栏不换行；接收错误可点状态行查看完整信息。
2. 点照片或全屏图标：工具栏、信息层、缩略图消失，返回键与退出按钮可恢复；双击只缩放，不触发全屏。
3. 放大并选择历史照片后旋转：选中的文件、缩放和位置保留；手机横屏出现右侧双列照片。
4. Pad 横屏、竖屏及分屏：按窗口宽度切换侧栏/底部胶片条，按钮和缩略图不越界。
5. 打开图库：手机和 Pad 自动计算列数；滚动后缩略图与文件名一致，点照片回到预览并暂停跟随。
6. 看历史照片时继续拍摄：关闭跟随不跳图，开启跟随后显示最新接收的照片。导出仍保存完整原文件。

手机横竖屏显示已检查；其他交互与 Pad 实机需逐项验收。

## 0.4.1 保存位置检查

1. 更多菜单和设置可正常打开，选择取消不更改保存位置，点保存后重新打开仍保持选中值。
2. 选 App 图库后拍 JPEG：App 可查看，系统相册不自动新增；手动导出可出现相册原图，再次导出不生成重复副本。
3. 选本地相册后拍 JPEG：系统相册 XT5Tether 与 App 都可查看；结束传输后 App 私有目录不保留同一张临时原图。
4. 杀进程后重开 App：本应用已保存的相册照片仍可浏览；已存在的 App 图库照片不因设置切换而移动或删除。
5. RAW+JPEG：JPEG 在相册，RAF 原文件在下载；App 从 URI 正常读取 RAF 内嵌预览。
6. 相册保存遇到存储不足等错误时：提示错误、完整原图留在 App 图库，不释放相机未完成对象；恢复后手动导出可再次保存。

补充实测：小米平板 25032RP42C 已安装最终 0.4.1，横竖屏显示与旋转保留照片、Wi-Fi 联机接收 11,548,400 字节 JPEG 到 App 图库已验证。旋转设置已恢复；其他矩阵项目仍按上表逐项验收。

## 0.8.0 图库多选删除验收

仅对专门拍摄的测试照片执行删除：

1. 图库右上角点多选、取消；长按已保存照片进入多选。选中数量与角标一致，单击继续勾选／取消，顶底栏与照片网格边界保持稳定。
2. 全选仅包含已保存照片；待保存条目不可删除。多选和删除确认期间新拍的照片不自动加入选择或本批删除。
3. 点删除后取消，所有原图仍在。确认删除测试照片后，它从图库、侧栏与当前预览移除，重新打开图库不会复现。
4. 分别测试 App 私有 JPEG、自动保存到相册的 JPEG、手动导出且保留私有副本的 JPEG、Downloads 中的 RAF；核对确认范围内的本 App 副本同步删除。
5. 删除后仍有其他照片、只剩待保存照片、空图库三种状态均可正常显示；旋转、平板和窄窗口按钮不越界。
6. 独立 `device-checks` 应用复用生产代码测试临时照片，不针对主应用运行 Instrumentation；测试包安装被设备拦截时不将构建成功记为真机验证通过。

## 0.8.1 预览删除验收

1. 普通预览与全屏模式左上角均可见删除图标，更多菜单也有「删除当前照片」。空预览和待保存照片禁用删除。
2. 确认框显示原文件名；取消后原图仍在。弹窗期间拍摄并收到新照片，确认后只删除原先那张，新照片保留。
3. 无需打开图库即可确认删除，不因图库 Dialog 为空而闪退；图库、侧栏、预览同步刷新。回看中间、最旧、最后一张测试照片时，分别检查相邻照片回退与空状态。
4. 独立检查包新增上述临时照片用例；未运行的断言不计为真机通过。

## 0.8.2 缩略图长按与批量导出验收

1. 普通／全屏预览无删除叠层。右侧或底部缩略图长按后显示选中角标，以及继续多选、导出所选、删除所选菜单。
2. 点其他已保存缩略图继续勾选；待保存项不可选。检查全选、清空、取消、张数和跟随状态恢复，新拍照片不会自动加入；旋转后保留选择。
3. 仅用临时照片测试批量导出：JPEG 进入本地相册，RAF 进入下载目录；私有原图保留，重复导出不重复建立副本。单张失败不阻止其他项，失败项保留选择。
4. 取消删除确认保留所有照片；确认后仅删除冻结目标及 App 同名副本，新照片保留。右侧、底部、400 dp 窄窗口按钮不越界，进度不改变布局高度。

## 0.8.3 长按直接多选

长按右侧或底部已保存缩略图后，直接选中并显示勾选角标和操作栏，不弹出菜单；继续点其他照片可以多选。全选、清空、取消、批量删除确认和导出保持原有行为。

## 0.9.1 样式与拍摄参数验收

1. 检查手机／Pad 的卡片、边距、圆角和按钮；右上角连接、全屏、更多之间留空，工具栏在连接／进度变化时不改高度。
2. 设置 → 查看与显示 → 显示拍摄参数，开启并保存：两行 8 项显示；关闭立即隐藏，重新打开应用保持选择。取消设置不改变偏好。
3. 点参数栏查看 17 项详细信息；与相机及系统相册核对。切到新照片、待保存预览、空状态时不得残留上一张参数，缺失显示 —。
4. 全屏和横竖屏切换时参数随开关显示，工作区尺寸不因 EXIF 更新而跳动，文字不越界。
5. 只读真机工具复用生产代码检查现有照片 EXIF，不针对主应用运行 Instrumentation、不安装测试包、不修改或删除原图。

## 0.9.2 原图下载时机

1. 设置 → 原图下载时机，默认停拍 3 秒；切到立即下载，保存后不重连单拍，核对先预览后直接开始原图。重开设置／应用核对选项保留，取消不改变模式。
2. 同一连接改回停拍 3 秒，拍 3 张，核对预览仍先出现、停拍后补原图；已有队列保留，积压 8 项仍可提前保存。
3. 手动暂停后选择立即下载，不应自动开始原图；点击开始保存后按所选方式处理。正在传输的一张完整原图应正常结束，不因设置切换截断。
4. 检查队列提示能区分立即下载与停拍 3 秒，USB 显示自动接收；原图字节与文件数量完整，发布成功后才释放相机对象。
